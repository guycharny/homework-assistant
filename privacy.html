Privacy Policy – Homework Assistant

Last updated: September 27, 2026

What data is accessed

With the user's consent, Homework Assistant uses read-only Google Classroom permissions to access the user's course list, coursework, and the status of the user's own submissions.

How the data is used

The data is used only to display the student's upcoming and overdue assignments and to generate homework reminders for the student and their parent.

Storage and sharing

An access token is stored locally on the family's own computer. Classroom data is not sold, not shared with third parties, and not used for advertising. Nothing is written back to Google Classroom.

Google API Services User Data Policy

Homework Assistant's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
